# ADD-ON VEHICLES
#
# Una riga per veicolo, quattro campi separati da |
#
#     nomemodello | Marca | Nome modello | Categoria
#
#   nomemodello  = quello con cui lo spawni, letto dai file del dlc (es. rs322)
#   Marca        = Audi, BMW, Ferrari, ...   -> primo livello del menu ADD-ONS
#   Nome modello = RS3, M6, ...              -> come lo leggi nella lista
#   Categoria    = Sports, SUVs, Vans, ...   -> secondo livello del menu
#
# Nel menu vedi:  ADD-ONS > Audi > Sports > RS3
# In piu' il veicolo finisce anche nella categoria generale dei VEICOLI,
# li' scritto come "Audi RS3".
#
# Categorie di GTA (inglese o italiano):
#   Compacts/Compatte  Sedans/Berline  SUVs/SUV  Coupes/Coupe
#   Muscle  Sports Classics/Sportive classiche  Sports/Sportive
#   Super  Motorcycles/Moto  Off-road/Fuoristrada  Industrial/Industriali
#   Utility/Utilitari  Vans/Furgoni  Cycles/Bici  Boats/Barche
#   Helicopters/Elicotteri  Planes/Aerei  Service/Servizi
#   Emergency/Emergenza  Military/Militari  Commercial/Commerciali  Trains/Treni
#
# Puoi anche scrivere una categoria tua (es. Drift, Rally): viene creata.
# Marca o categoria vuote finiscono sotto "Altro".
# I modelli non installati vengono ignorati in automatico.
